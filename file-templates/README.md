# File templates

Source templates consumed by `npm run create-comp`.

- `Kirby/fileTemplate_kirby_comp.php` — component markup + gia mount attributes
- `Kirby/fileTemplate_kirby_snippet.php` — plain snippet
- `fileTemplate_NewComp.js` — gia component class
- `fileTemplate_init.js` — component init method
- `fileTemplate_api.js` — component API method
- `fileTemplate_ebh.js` — eventbus handler
- `fileTemplate_stChH.js` — state-change handler

Vendored into this project rather than consumed as a git submodule. Upstream:
https://github.com/joh-sch/file-templates
